Built for the Builder

NEXUS is a demo storefront powering a deliberately vulnerable MCP server. Every product page is backed by an MCP tool — and every tool has a flaw our red-team scanner is designed to find.

We also built an interactive AI Shopping Agent sandbox (bottom-right bubble) so you and your professors can see the agent call the MCP tools live, revealing the vulnerabilities in real-time.

  • PII leakage — customer profiles expose SSN, cards, API keys
  • Path traversal — invoice download reads arbitrary files
  • Prompt injection — admin/debug descriptions poison tool metadata
  • SQL / expression injection — search & discount interpret attacker input
  • Resource exposure — config, logs, DB creds leaked via MCP resources
