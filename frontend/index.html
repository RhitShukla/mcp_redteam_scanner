Comprehensive attack modules

Each attack is non-destructive, production-safe, and designed to find real vulnerabilities without breaking your system.

A SERIES

Tool Discovery Attacks

Probes for hidden or duplicated tools, excessive resource exposure, and schema manipulation vulnerabilities.

B SERIES

Execution Attacks

Tests input validation by attempting parameter injection, SSRF probes, and path traversal against your tools.

D SERIES

Sensitive Data Attacks

Scans tool responses for PII, credentials, API keys, tokens, and other sensitive data exposure.

E SERIES

Infrastructure Attacks

Tests underlying infrastructure including weak authentication, TLS origin validation, and rate limit probing.
